3.1 弱點、威脅分類與攻擊手法
關於 MITRE ATT&CK 中的橫向移動 (Lateral Movement) 戰術 (Tactic), 下列何項錯誤?
A
遠端服務破解 (Exploitation of Remote Services) 屬於此類戰術
B
內部魚叉釣魚 (Internal Spearphishing) 屬於此類戰術
C
橫移工具傳輸 (Lateral Tool Transfer) 屬於此類戰術
D
本地資料取得 (Data from Local System) 屬於此類戰術
答案解析
橫向移動 (Lateral Movement, TA0008) 戰術是指攻擊者在成功入侵網路環境中的某個系統後，試圖移動到網路中其他系統的技術。
(A) Exploitation of Remote Services (T1210): 攻擊者利用遠程系統上的漏洞來獲得對該系統的訪問權限，這是典型的橫向移動技術。
(B) Internal Spearphishing (T1534): 攻擊者利用已盜用的內部帳戶向其他內部使用者發送釣魚郵件，以誘騙他們執行惡意程式或洩漏憑證，從而擴散到其他主機，屬於橫向移動。
(C) Lateral Tool Transfer (T1570): 攻擊者將工具（如惡意軟體、遠端存取工具）從一個已入侵的系統複製到另一個目標系統，以輔助進一步的橫向移動或活動，本身也是橫向移動的一環。
(D) Data from Local System (T1005): 這個技術屬於「收集」 (Collection, TA0009) 戰術，指攻擊者在已入侵的本地系統上收集感興趣的檔案或資訊，不涉及移動到其他系統。因此，此項錯誤。

3.1 弱點、威脅分類與攻擊手法
2022 年 8 月美國眾議院議長Nancy Pelosi 日前來台訪問, 造成台灣有些公私部門遭受分散式阻斷服務攻擊 (Distributed Denial-of-Service Attack, DDoS)。關於 DDoS 攻擊與當時事件的敘述, 下列何者錯誤?
A
當時我國行政院數位發展部部長唐鳳提出的防禦方式是採取以 Web3 為主的不對稱防禦架構
B
當時我國政府為了解決此問題, 利用「流量清洗」的方式去對抗, 投入大量資源與成本多設專線去阻擋
C
DDoS 攻擊可以分成消耗網路頻寬與擷取網路上傳輸封包資訊兩種動作
D
目前市面上有販售 DDoS 攻擊的服務, 更加難以有效偵查 DDoS 攻擊
答案解析
(A) 唐鳳部長當時提出的概念是利用 InterPlanetary File System (IPFS) 這類Web3 分散式技術來增加內容的韌性，使其難以被單點 DDoS 攻擊癱瘓，可視為一種不對稱防禦思路。敘述大致符合當時的說法。
(B) 政府或相關單位應對 DDoS 攻擊時，確實可能採用流量清洗服務（由專業廠商提供）來過濾惡意流量，這需要投入資源。敘述符合常見的應對方式。
(C) DDoS 攻擊的主要目的是透過大量無效或惡意流量來耗盡目標系統的網路頻寬、連線數或運算資源，使其無法回應正常請求，達成「阻斷服務」的目的。它通常不涉及「擷取」網路上傳輸的封包資訊（那是竊聽或中間人攻擊的範疇）。因此，這個描述錯誤。
(D) 地下市場確實存在提供 DDoS 攻擊服務（DDoS-for-hire 或 Booter/Stresser services），這使得發動攻擊的門檻降低，來源更加分散，增加了防禦和溯源的難度。敘述正確。

3.1 弱點、威脅分類與攻擊手法
下列哪些攻擊手法可以透過遠端攻擊網路伺服器? (複選)
A
Ping Flooding
B
DDoS
C
簡單配對攻擊 (Secure Simple Pairing Attacks)
D
Wi-Fi MITM (Man-in-the-Middle)
答案解析
分析各攻擊手法是否能遠端攻擊網路伺服器：
(A) Ping Flooding：一種阻斷服務攻擊，攻擊者從遠端向目標伺服器發送大量 ICMP Echo 請求（ping），耗盡目標的頻寬或處理能力。可以遠端攻擊網路伺服器。
(B) DDoS：分散式阻斷服務攻擊，利用多個來源（通常是受控的殭屍網路）從遠端同時向目標伺服器發動攻擊，目的在於癱瘓服務。可以遠端攻擊網路伺服器。
(C) 簡單配對攻擊 (Secure Simple Pairing Attacks)：這通常與藍牙 (Bluetooth) 技術的配對過程相關，攻擊者需要在物理上接近目標設備才能利用配對過程中的漏洞，不適用於遠端攻擊網路伺服器。
(D) Wi-Fi MITM：Wi-Fi 中間人攻擊，攻擊者通常需要與受害者處於同一個 Wi-Fi 網路環境（或建立惡意熱點），以攔截或竄改受害者與網路伺服器之間的通訊，而非直接遠端攻擊伺服器本身。
因此，可以遠端攻擊網路伺服器的手法是 (A) 和 (B)。

3.2 防護與應變實務
【題組1】情境：現在你是一間企業的資安專責人員。最近, 你發現一個未被掌握的內部系統漏洞, 而且發現了來自不明來源的異常網路流量。你的任務是分析這個威脅, 並提出適當的回應策略。
針對這個不明的異常流量, 第一步你該如何確認本項威脅來源?
A
關閉所有的內部網路
B
通知所有員工有潛在的威脅
C
進行詳細的威脅與風險分析
D
立即去法院按鈴申告
答案解析
面對不明異常流量和已知內部漏洞，首要任務是理解情況。
(A) 關閉所有內部網路過於激烈，會嚴重影響業務運作，且未必能阻止已潛伏的威脅，不是明智的第一步。
(B) 在未確認威脅性質和範圍前就通知所有員工可能引起不必要的恐慌，且對釐清來源幫助有限。
(C) 進行詳細的威脅與風險分析，包括分析異常流量的來源 IP、目的端口、流量模式、時間，並結合已知漏洞的情況，判斷兩者是否相關，評估潛在的威脅類型（如外部掃描、內部擴散、資料外洩等）及其風險，這是釐清狀況、找出來源的合理且必要的第一步。
(D) 在未有明確事證前就去法院申告不切實際。
因此，最適合的第一步是 (C)。

【題組1】情境如前所示。在瞭解詳細的威脅情況後, 第一步你需要與哪一個組織內部團隊合作?
A
市場行銷團隊
B
事件回應團隊
C
威脅分析團隊
D
行銷風險評估團隊
答案解析
在初步分析並了解威脅情況後（即使還不完全清楚），識別到異常流量和漏洞，這已經構成一個潛在的資安事件或需要立即處理的威脅。 (A) 市場行銷團隊與技術性的威脅分析和處理無關。
(B) 事件回應團隊 (Incident Response Team, IRT 或 CSIRT) 的職責就是處理已發生或正在發生的資安事件，包括進一步調查、遏制、根除和復原。這是最需要優先合作的團隊。

(D) 行銷風險評估團隊與此技術事件無關。
因此，應優先與事件回應團隊合作。

3.1 弱點、威脅分類與攻擊手法
【題組1】情境如前所示。經過分析這個威脅來源是透過郵件附件進行攻擊的, 這個攻擊手法對應到 Cyber Kill Chain 的哪一個階段?
A
Weaponization (武器化)
B
Installation (安裝)
C
Delivery (投遞)
D
Exploitation (漏洞利用)
答案解析
洛克希德·馬丁公司的 Cyber Kill Chain 模型描述了攻擊者執行攻擊的典型階段：
  1. Reconnaissance (偵察)
  2. Weaponization (武器化): 攻擊者準備惡意酬載（如製作帶有惡意程式的附件）。
  3. Delivery (投遞): 將惡意酬載傳送給目標，例如透過電子郵件附件、惡意連結、USB 隨身碟等。
  4. Exploitation (漏洞利用): 惡意酬載利用目標系統上的漏洞來執行程式碼。
  5. Installation (安裝): 安裝惡意軟體或後門到目標系統。
  6. Command & Control (C2, 命令與控制): 惡意軟體與攻擊者建立通訊管道。
  7. Actions on Objectives (目標達成): 攻擊者執行其最終目的（如竊取資料、破壞系統）。
題目描述威脅是「透過郵件附件進行攻擊」，這個動作屬於將武器化的酬載傳送給受害者的階段，對應到 Delivery (投遞) 階段。

3.2 防護與應變實務
【題組1】情境如前所示。承上題, 在這樣的情況下, 為了提高你的資訊安全防護並防止未來的攻擊, 你可以採取下列哪些措施? (複選)
A
增強員工的資訊安全意識, 如定期的資訊安全訓練
B
強化網路監控以偵測不尋常的活動
C
建立並維護一個更新的災難恢復計畫
D
不斷地升級電腦硬體, 即使沒有發現任何威脅
答案解析
針對透過郵件附件的攻擊，並著眼於防止未來攻擊，應採取以下措施：
(A) 郵件附件攻擊通常依賴使用者點擊或開啟。因此，提高員工資安意識，使其能夠識別惡意郵件、不隨意開啟不明附件，是非常重要的預防措施。
(B) 強化網路監控（如 IDS/IPS、SIEM、EDR）可以幫助及早偵測到惡意活動（如惡意附件下載、惡意軟體執行、異常連線），從而縮短回應時間，降低損害。
(C) 即使預防措施完善，攻擊仍可能成功。災難恢復計畫（包括資料備份）是確保在系統遭受破壞（如勒索軟體加密）後能夠快速恢復的關鍵後備措施。
(D) 不斷升級硬體與提升資安防護能力無直接必然關係。重點在於軟體更新（作業系統、應用程式修補）、安全配置以及採用有效的安全防護方案，而非盲目升級硬體。
因此，可以採取的合理措施是 (A)、(B)、(C)。

4.1 安全維運
當使用者利用帳號密碼登入系統時, 密碼的儲存基本原則是不可以直接用明文方式存放於資料庫中, 因此密碼通常利用加密 (Encryption) 或是雜湊 (Hash) 的方式進行編碼轉換。關於雜湊函數的敘述, 下列何者錯誤?
A
雜湊原理是限制輸入長度為 8 字元以上並透過雜湊函數進行計算, 計算後會得到一樣長度的密文
B
常見的雜湊函數有 MD5、SHA-1 及 SHA-2 等
C
輸入的原始字串只差一個字元, 透過雜湊函數得到的結果會差異很大 (雪崩效應)
D
雜湊函數具有不可逆的特性, 無法利用雜湊值計算取得原始資料
答案解析
關於雜湊函數的特性：
(A) 雜湊函數可以處理任意長度的輸入，並產生固定長度的輸出（雜湊值）。它並沒有限制輸入長度必須為 8 字元以上。這個限制通常是應用系統對密碼長度的要求，而非雜湊函數本身的限制。因此，此敘述錯誤。
(B) MD5, SHA-1, SHA-2 (包括 SHA-256, SHA-512) 都是常見的雜湊函數（儘管 MD5 和 SHA-1 已被認為不安全，不應用於密碼儲存）。
(C) 好的雜湊函數具有雪崩效應 (Avalanche Effect)，即輸入的微小改變（如一個字元）會導致輸出的雜湊值發生巨大且不可預測的變化。
(D) 雜湊函數是單向的（不可逆），從輸出的雜湊值無法反推出原始的輸入資料。這使得它適合用於儲存密碼（儲存雜湊值而非明文）。
因此，錯誤的敘述是 (A)。

3.1 弱點、威脅分類與攻擊手法
根據常見的弱點類型, 下列何種是 Web 應用程式最常見的安全弱點?
A
SQL Injection: SQL 注入攻擊
B
Distributed Denial-Of-Service: DDoS 攻擊
C
Local File Inclusion: LFI 本地端檔案內容揭露
D
Cross Site Request Forgery: CSRF 跨站請求偽造
答案解析
分析選項中的弱點/攻擊類型：
(A) SQL Injection (SQL 注入)：攻擊者將惡意的 SQL 語句插入到應用程式的輸入中，欺騙後端資料庫執行非預期的指令，可能導致資料洩漏、竄改或系統控制權喪失。這是 Web 應用程式非常經典且常見的高風險弱點。
(B) DDoS 攻擊：目標是癱瘓服務，屬於可用性攻擊，雖然可能針對 Web 伺服器，但通常被視為網路層或基礎設施層面的攻擊，而非應用程式本身的邏輯弱點。
(C) LFI (本地檔案包含)：允許攻擊者讀取伺服器上任意檔案的弱點。常見，但其普遍性可能略低於注入類攻擊。
(D) CSRF (跨站請求偽造)：誘騙已登入的使用者在不知情的情況下，向Web 應用程式發送非預期的請求。也是常見弱點，但近年來由於框架的內建防護和 SameSite cookie 等機制，其風險有所降低。
綜合來看，根據 OWASP Top 10 等權威報告，注入類攻擊（包括 SQL Injection）長期以來一直被認為是 Web 應用程式最嚴重且最常見的弱點之一。因此，(A) 是最佳答案。

3.1 弱點、威脅分類與攻擊手法
關於 MITRE ATT&CK 中的輸入擷取 (Input Capture) 技術, 下列何項錯誤?
A
無法使用預防控制 (Preventive Controls) 輕易緩解此技術
B
無法透過觀察驅動程式載入 (Driver Load) 活動來偵測此技術
C
可觀察系統註冊機碼 (Windows Registry) 活動來偵測此技術
D
可觀察程序建立 (Process Creation) 活動與元資料 (Process Metadata) 來偵測此技術
答案解析
輸入擷取 (Input Capture, T1056) 是MITRE ATT&CK 中的一種技術，屬於「收集」 (Collection) 和「憑證存取」 (Credential Access) 戰術。它指的是攻擊者記錄使用者的輸入，如鍵盤敲擊 (Keylogging)、滑鼠點擊、螢幕截圖等，以竊取密碼、敏感資訊等。
(A) 這類攻擊通常透過惡意軟體實現，預防控制（如防毒軟體、應用程式白名單、限制軟體安裝）可以阻止惡意軟體的執行，從而緩解此技術。聲稱無法輕易緩解可能不準確，但相對偵測而言，預防可能更困難一些。
(B) 某些鍵盤記錄器或輸入擷取工具可能需要安裝特定的驅動程式（尤其是核心層的）。因此，監控異常的驅動程式載入活動是可能偵測到此類技術的一種方式。聲稱「無法」透過此方式偵測是錯誤的。
(C) 惡意軟體為了實現開機自啟動或儲存配置，常常會修改註冊機碼。監控可疑的註冊機碼變更（特別是與鍵盤、輸入法、自啟動相關的機碼）有助於偵測此技術。
(D) 執行輸入擷取的惡意軟體通常會以一個新的程序運行。監控異常的程序建立，並分析其元資料（如程序名稱、路徑、簽章等），是偵測此類惡意活動的重要手段。
因此，錯誤的敘述是 (B)。

4.1 安全維運
關於進行網路架構設計的敘述, 下列何者較「不」適當?
A
應區分內外網
B
網站跟資料庫最好在不同網段
C
目錄伺服器 AD (Active Directory) 應該放在辦公網段
D
可以透過 VLAN 切割網段
答案解析
安全的網路架構設計原則：
(A) 區分內部可信網路與外部不可信網路，並設置邊界防護（如防火牆），是基本的安全原則。
(B) 將網站伺服器（通常放在 DMZ 或特定應用區）與資料庫伺服器（應放在更安全的內部網段）分開，並嚴格限制它們之間的通訊，是常見的多層式架構，有助於保護後端資料庫。
(D) VLAN (Virtual Local Area Network) 是一種在第二層實現網路分割的常用技術，可以將不同部門、不同安全等級的設備邏輯上隔離在不同的廣播域。
(C) AD 伺服器是組織最核心的基礎設施之一，包含所有身份驗證和授權資訊。將其直接放在使用者眾多、風險相對較高的辦公網段（與一般使用者電腦在同一網段）是非常不安全的做法。AD 伺服器應放置在受到嚴格保護、存取控制嚴密的獨立網段（如伺服器區或核心服務區）。因此，此敘述最不適當。

D

答案解析
比較三種測試方法的特性：
  • **弱點掃描 (DAST/Network Scan):** 自動化工具，主要掃描已知的漏洞特徵（如特定軟體版本漏洞、常見配置錯誤）。發現數量中等，速度快，但無法發現未知漏洞或複雜邏輯問題，誤判率（False Positive）可能存在。
  • **滲透測試 (Penetration Testing):** 人工為主，模擬真實攻擊。能發現已知和未知漏洞、業務邏輯缺陷、權限控制問題等。發現的通常是可實際利用的風險，誤判率相對較低。但覆蓋範圍可能受限於時間和測試人員能力，發現的弱點「數量」不一定最多。
  • **源碼檢測 (SAST):** 直接分析程式碼。能全面掃描所有程式碼路徑，發現潛在的編碼層級安全缺陷（如注入、XSS、不安全函數使用）。通常能發現大量潛在問題，數量最多。但可能產生較多誤判（理論上有風險但實際無法利用），且無法發現運行時配置錯誤或業務邏輯問題。
(A) 滲透測試發現的是可利用風險，但不一定數量最多。
(B) 滲透測試因為有人工驗證，誤判率通常相對較低。SAST 的誤判率可能更高。
(C) SAST 因為掃描所有程式碼，通常能發現最多數量的潛在問題點。正確。
(D) SAST 主要關注程式碼本身的缺陷，難以發現需要理解整體業務流程的商業邏輯問題。滲透測試或人工程式碼審查更能發現這類問題。
因此，較為正確的敘述是 (C)。

【題組4】情境如前所示。在檢測後發現命令注入弱點 (Command Injection), 請問應採用下列何項進行修復?
A
過濾特殊字元及允許命令之白名單
B
不允許大寫字元
C
過濾 Unicode 字元
D
使用防毒軟體
答案解析
命令注入 (Command Injection) 弱點發生在應用程式將使用者提供的輸入作為作業系統命令的一部分來執行時，若未經適當處理，攻擊者可注入惡意的命令（如使用 `;`, `&&`, `|` 等特殊字元）來執行非預期的操作。
修復方法：
  • **避免將使用者輸入直接傳遞給作業系統命令**：這是最根本的方法，盡量使用安全的 API 來實現所需功能。
  • **輸入驗證與過濾**：如果無法避免，則必須對使用者輸入進行嚴格的驗證。
    • **過濾特殊字元**：移除或編碼在作業系統命令中有特殊意義的字元（如 `&`, `|`, `;`, `<`, `>`, `` ` ``, `\`, `\n` 等）。
    • **白名單驗證**：只允許輸入符合預期格式或內容的值（例如，只允許數字、只允許特定選項）。如果需要執行的命令是固定的幾個選項，可以使用白名單來限制使用者只能選擇這些預設命令，而不是讓他們輸入任意字串。
(A) 結合過濾特殊字元和建立允許執行的命令白名單，是修復命令注入的有效方法。
(B) 限制大小寫與命令注入無關。
(C) Unicode 編碼本身不是問題，問題在於輸入中包含的特殊命令字元。單純過濾 Unicode 字元無法解決問題，且可能導致正常功能異常。
(D) 防毒軟體主要偵測惡意檔案，無法阻止應用程式本身因編碼不當而執行的命令注入攻擊。
因此，最適合的修復方法是 (A)。
