2.1 弱點、攻擊與攻擊實務
關於 MITRE ATT&CK 中的憑證存取 (Credential Access) 戰術 (Tactic), 下列何項錯誤?
A
中間人攻擊 (Adversary-in-the-Middle) 屬於此類戰術
B
暴力破解攻擊 (Brute Force) 屬於此類戰術
C
密碼政策探索 (Password Policy Discovery) 屬於此類戰術
D
變造網站憑證 (Forge Web Credentials) 屬於此類戰術
答案解析
MITRE ATT&CK 的憑證存取 (Credential Access, TA0006) 戰術包含攻擊者竊取帳號名稱和密碼的技術。
(A) 中間人攻擊 (T1557): 可以攔截網路流量，可能截獲未加密的憑證，屬於憑證存取。
(B) 暴力破解攻擊 (T1110): 透過嘗試大量密碼組合來獲取有效憑證，屬於憑證存取。
(C) 密碼政策探索 (T1201): 屬於探索 (Discovery, TA0007) 戰術，目的是了解目標系統的密碼規則（如長度、複雜度、效期），以便更有效地進行密碼攻擊，但不是直接存取憑證的行為。此敘述錯誤。
(D) 變造網站憑證 (T1606.001 - Forge Web Credentials: Cookies, T1606.002 - Forge Web Credentials: Web Session Cookie): 偽造Cookie或Session Token等網站憑證以冒充使用者身份，屬於憑證存取。
因此，錯誤的選項是 (C)。

2.2 作業安全實務
關於弱點掃描, 下列敘述何者錯誤?
A
網路弱點掃描用在尋找網路環境中的脆弱點, 舉凡開放的通訊埠及所代表之服務, 其服務是否透過未經加密的進行傳輸, 或服務未更新漏洞
B
應用程式弱點掃描主要針對特定應用程式(尤其是網頁伺服器及其資料庫)的程式及應用環境(例如:Apache 版本漏洞), 但主要是尋如 SQL 注入、跨站腳本、敏感目錄外洩…等可被攻擊之漏洞
C
主機弱點掃描用在檢查個別主機的脆弱點, 例如主機效能負載對外服務能力, 或是識別主機防毒系統是否更新
D
常見工具, 有 OWASP ZAP, OpenVAS, Nessus…等
答案解析
(A) 正確描述了網路弱點掃描的範圍和目的，包括識別開放埠、服務、加密狀態和已知漏洞。
(B) 正確描述了應用程式弱點掃描（Web 掃描）的重點，包括底層（如Apache漏洞）和應用層（如SQLi, XSS）的漏洞。
(C) 主機弱點掃描檢查的是主機作業系統、已安裝軟體和服務的已知漏洞和安全配置錯誤。它不檢查「效能負載對外服務能力」（這是效能測試或壓力測試的範圍），通常也不直接識別防毒軟體是否更新（雖然可能檢查防毒服務是否運行或存在已知漏洞）。此敘述錯誤。
(D) OWASP ZAP 是網頁應用程式掃描工具。OpenVAS 和 Nessus 是通用的網路和主機弱點掃描工具。這些都是常見的弱點掃描工具。
因此，錯誤的敘述是 (C)。

這個決策立即吸引了公司的資安政策制定者 Alex 的注意, 身為公司資安政策訂定者, 在面對公司研發團隊必須使用 Windows Subsystem for Linux 2 (WSL2), 必須對其資安攻防應建立那些安全管理措施。
A

B
保持 Windows 和 Linux 子系統的定期更新
C

這個腳本專門設計來利用 WSL2 環境中的漏洞, 目標是獲取公司的敏感數據和內部系統的控制權駭客計劃利用 Windows Subsystem for Linux (WSL) 來進行網絡入侵。
A
在 Windows 創立一個隱藏的管理員帳戶, 以便未來存取
B
為了直接加密 Windows 系統文件, 進行勒索軟體攻擊
C
通過 WSL 環境檢索並傳送 Windows 系統日誌, 以分析可能的弱點
D
利用 WSL 執行環境的特性, 隱藏網路流量, 以掩蓋資料外洩行為

情境描述駭客利用 WSL 的互操作性漏洞部署惡意腳本，目標是獲取敏感數據和內部系統控制權，並進行內部網路入侵。
分析選項目的：
(A) 建立隱藏帳戶是維持存取 (Persistence) 的一種手段。
(B) 勒索軟體是為了勒索金錢 (Impact)。
(C) 檢索系統日誌是為了收集資訊或尋找弱點 (Discovery)。
(D) WSL 可以執行 Linux 工具，可能被用來建立隱蔽的通訊隧道或混淆網路流量，以掩蓋其資料外洩 (Exfiltration) 的行為。考慮到駭客目標包含「獲取敏感數據」，隱藏資料外洩的流量是很可能的後續動作。
結合情境「進行內部網路入侵」、「獲取敏感數據」和「利用互操作性漏洞」，選項 (D) 描述利用 WSL 特性來隱藏其惡意活動（特別是資料外洩），是一個符合邏輯且進階的攻擊目的。其他選項雖然也可能是攻擊手法，但 (D) 更能體現利用 WSL 進行隱匿操作的意圖。

在進一步的調查中, Alex 發現駭客計劃利用 GTFOBins 來執行權限提升和安全環境逃逸。這個發現迫使他對 WSL2 的安全措施進行了再次強化。
GTFOBins 是一個關於 Unix 二進制文件如何被用於權限提升、文件操作、能力提升以及其他安全環境逃逸的技術文件。
A
在 WSL 中使用防病毒軟體
B
在 WSL 中安裝弱點掃描工具
C
禁用 WSL 的網路功能
D
偵測與記錄用戶對敏感二進制文件的使用
答案解析
GTFOBins 列出了許多正常的 Unix/Linux 二進制文件（系統工具）如何被濫用於權限提升或安全逃逸。<這意味著攻擊者使用的工具本身不是惡意軟體，傳統的防毒軟體 (A) 可能無法偵測。安裝弱點掃描工具 (B) 無助於防止這些合法工具被濫用。禁用網路功能 (C) 可能影響正常使用，且無法阻止本地的權限提升。

WSL 惡意軟體有時基於開源的程式碼, 使得其較難被檢測出來
B
這些惡意軟體變種包括能夠遠端存取裝置、執行任意程式碼的複雜功能
C
目前的防毒解決方案皆能主動偵測、有效識別和防禦這些基於 WSL 的惡意軟體

企業資安事件類型「不」包含下列何項?
A
機房漏水
B
備用發電機啟動故障
C
外部廠商發生資料外洩
D
私人手機遺失
答案解析
資安事件通常指任何危及資訊系統或資料的機密性、完整性或可用性 (CIA) 的事件。
(A) 機房漏水可能損壞伺服器、儲存設備等資訊資產，影響可用性和完整性，屬於環境安全事件，可歸類為廣義的資安事件。
(B) 備用發電機故障可能導致電力中斷時系統無法持續運作，影響可用性，屬於影響營運持續的事件，也可視為廣義的資安事件（影響可用性）。
(C) 外部廠商（供應鏈）的資料外洩如果涉及企業的敏感資料或客戶資料，則直接構成企業的資安事件（機密性受損）。
(D) 私人手機遺失本身不直接構成企業的資安事件，除非該手機存有未受保護的企業敏感資料或可用於存取企業系統（例如未啟用 MFA 的郵件或 VPN 帳號）。單純遺失私人手機，與企業資產或CIA 的直接關聯性最低。
因此，(D) 最不可能直接被歸類為企業的資安事件。

進行資安事件處置時, 下列做法何者錯誤?
A
將漏洞修補以防止再發生
B
原始稽核紀錄可以刪除
C
確認事件根因是必要的
D
可以委託外部專業廠商進行
答案解析
資安事件處置的正確做法：
(A) 事件處置的根除 (Eradication) 和復原 (Recovery) 階段，以及事後活動 (Post-Incident Activity)，都包含修補被利用的漏洞，以防止事件重複發生。
(C) 找出事件的根本原因 (Root Cause Analysis) 是事後檢討的關鍵，有助於制定更有效的預防措施。
(D) 許多組織會委託外部的資安專家或事件應變 (IR) 廠商來協助處理複雜的資安事件，這是常見且合適的做法。
(B) 原始稽核紀錄（Log）是進行事件調查、數位鑑識和責任追究的重要證據，絕對不可以隨意刪除，尤其是在事件處置過程中。刪除紀錄會妨礙調查，甚至可能違法。此做法嚴重錯誤。
因此，錯誤的做法是 (B)。

購買符合公司規格流量的防火牆
B
定期更新防毒軟體的病毒碼
C
針對內部系統、網路、軟體進行多層次的安全控制

於面向網際網路之主機執行弱點掃描以識別系統弱點並修復
