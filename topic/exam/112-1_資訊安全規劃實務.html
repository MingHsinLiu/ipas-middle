1.1 ISMS建置實務與法規遵循
X 公司為在中華民國註冊登記之公司, 該公司將於 2023 年導入資安管理制度, 並預計於 2024 年第一季通過國際資安驗證, 請問下列何項制度最適合 X 公司做為導入資訊安全管理制度依循之參考?
A
ISO/IEC 27001 : 2013
B
ISO/IEC 27004 : 2016
C
ISO/IEC 20000-1 : 2018
D
ISO/IEC 27001 : 2022
答案解析
ISO/IEC 27001 是國際上最廣泛採用的資訊安全管理系統 (Information Security Management System, ISMS) 標準。
(A) ISO/IEC 27001:2013 是舊版本的標準。
(B) ISO/IEC 27004 提供資訊安全管理績效衡量的指引，是輔助 ISMS 的標準，而非 ISMS 的主體要求。
(C) ISO/IEC 20000-1 是IT 服務管理 (IT Service Management, ITSM) 的標準，關注 IT 服務的交付與支援流程。
(D) ISO/IEC 27001:2022 是 ISMS 的最新版本（於 2022 年 10 月發布）。公司計畫在 2023 年導入並於 2024 年通過驗證，理應採用最新的有效版本作為依循標準。
因此，最適合的參考標準是 ISO/IEC 27001:2022。

1.2 資安管理實務/架構規劃
【題組1】背景描述：A公司為某先進產品的製造商, 該公司主要據點 B 與 C 分散在國內兩地, 距離約 20 km, 其主要客戶位於歐洲地區, 該公司十分重視資訊安全及品質管理, 先前已通過 ISO 9001、ISO 27001 及 ISO 27701 等相關標準的驗證。據點 B 主要主要包含的業務與技術服務部門, 據點 C 主要包含管理部門、資訊部門及相關研發、製造部門。該公司據點 B 與據點 C 兩地的通訊, 在成本考量下, 最終分別租用業者 D 的網際網路接取服務, 以連接網際網路(Internet)。近日業務部門的印表機突然印出紙本的勒索信, 信中表示該公司的電腦已被駭客組織 E 入侵, 需支付高額的金錢, 否則將進一步把公司的電腦資料加密。經調查後發現, 業務部門為了方便業務人員從公司外部直接列印資料, 而私自將該部門的印表機設定使用公有 IP (Public Internet Protocol), 且部門中的其他電腦皆位於啟用 NAT(Network Address Translation) 功能的防火牆後方, 請問最有可能被入侵的網路節點?
A
據點 C 中資訊部門的電腦
B
據點 B 中業務部門的電腦
C
據點 B 中技術服務部門的電腦
D
印表機遭惡意濫用
答案解析
分析情境：
  • 業務部門（據點B）的印表機被設定了公有 IP，直接暴露在網際網路上。
  • 其他電腦（包括業務部門的電腦）位於 NAT 防火牆之後，受到一定程度的保護，不易從外部直接存取。
  • 勒索信是從該印表機印出的。
推論：
  • 直接暴露在網路上的設備（印表機）是最容易受到外部攻擊的目標。
  • 攻擊者可能掃描到這個具有公有 IP 的印表機，並利用其自身的漏洞（印表機韌體、未設密碼的控制介面等）或弱密碼入侵。
  • 入侵印表機後，攻擊者可能將其作為跳板進一步攻擊內部網路（儘管有防火牆），或者直接利用印表機執行某些操作，例如列印勒索信。
(A), (B), (C) 這些電腦都位於 NAT 之後，被直接入侵的可能性相對較低（除非內部有惡意程式或已被其他方式入侵）。
(D) 印表機本身具有公有 IP，是最直接暴露的節點，最可能被入侵並惡意濫用（如此處被用來列印勒索信）。
因此，最有可能被入侵的網路節點是該印表機本身。

1.2 資安管理實務/架構規劃
【題組1 背景描述如前】為符合業務部門員工從公司外部列印資料的需求, 下列何種解決方案, 可以不需在印表機設定公有 IP (Public Internet Protocol) 的前提下達成此需求?
A
WAF (Web Application Firewall)
B
IDS (Intrusion Detection System)
C
VPN (Virtual Private Network)
D
EDR (Endpoint Detection and Response)
答案解析
需求是讓外部的員工能夠安全地列印到內部的印表機，同時避免將印表機直接暴露在公網上（不設定公有 IP）。這需要一個安全的遠端存取機制。
(A) WAF 主要用於保護 Web 應用程式，防止如 SQL Injection, XSS 等攻擊，與遠端列印無直接關係。
(B) IDS 用於偵測網路入侵，無法提供遠端存取功能。
(C) VPN 可以在外部使用者和公司內部網路之間建立一個加密的、安全的通道。外部員工連上 VPN 後，就如同在內部網路一樣，可以存取內部的印表機（印表機只需有內部 IP）。這是實現安全遠端存取的標準方法。
(D) EDR 是端點（電腦）上的偵測與回應方案，與提供遠端網路存取無關。
因此，最適合的解決方案是 (C) VPN。

【題組1 背景描述如前】因該公司是某先進產品的製造商, 若要進一步強化該公司製造場域部分的資訊安全 (Operational Technology), 宜再導入下列何種標準驗證較為合適?
A
BS 10012
B
IEC 62443-2-1
C
IEC 62443-2-4
D
ISO/IEC 27001
答案解析
Operational Technology (OT) 安全是指工業控制系統 (Industrial Control Systems, ICS) 或製造場域的資訊安全。IEC 62443 系列標準是國際上公認的工業自動化和控制系統資訊安全標準。
(A) BS 10012 是個人資訊管理系統標準。
(B) IEC 62443-2-1 規定了建立和維護工業自動化和控制系統 (IACS) 安全計畫的要求，適用於資產擁有者（Asset Owner），即製造商本身。導入此標準有助於強化 OT 場域的整體安全管理。
(C) IEC 62443-2-4 規定了 IACS 服務供應商（如系統整合商）的安全計畫要求。
(D) ISO/IEC 27001 是通用的 ISMS 標準，雖然也可應用於 OT 環境，但 IEC 62443 系列更專注於 OT/ICS 的特定需求和風險。題目提到公司已通過 ISO 27001，要進一步強化製造場域，導入 IEC 62443 更為合適。
因此，針對製造商強化自身製造場域 OT 安全，IEC 62443-2-1 是較合適的導入標準。

1.2 資安管理實務/架構規劃
組織擬採取「存取控制」構面之控制措施, 確保組織所保有的資通系統之安全防護, 請問關於控制措施的敘述, 下列何項錯誤?
A
遠端存取時使用者之權限檢查作業應於使用者端完成
B
超過組織所許可之閒置時間或可使用期限時, 系統自動將使用者登出
C
採最小權限原則, 僅允許使用者依組織任務及業務功能, 完成指派任務所需之授權存取
D
遠端存取之來源應為組織已預先定義及管理之存取控制點
答案解析
關於存取控制措施：
(A) 權限檢查（授權）是決定使用者能否存取特定資源的關鍵步驟，必須在受信任的伺服器端進行。如果在不可信的使用者端完成檢查，使用者可能繞過或竄改檢查結果，導致越權存取。這是嚴重的安全設計錯誤。
(B) 設定閒置超時自動登出，可以降低使用者離開座位時帳號被他人冒用的風險。
(C) 最小權限原則是存取控制的核心原則，確保使用者只擁有執行其工作所需的最低權限。
(D) 對於遠端存取，應限制其來源（如特定 IP、透過 VPN 或閘道器等已定義和管理的控制點），增加安全性。
因此，錯誤的敘述是 (A)。

1.2 資安管理實務/架構規劃
一個通過 ISO 27001:2013 驗證的組織, 在內部稽核活動中, 發現已離職員工的帳號仍沒有停用, 且進一步追查存取紀錄時, 發現其在離職後, 仍有登入存取部門共用資料夾的行為。請問對於該組織上述的狀況, 下列何項敘述最為合適?
A
該組織可能未落實使用者存取管理之程序
B
該組織可能未落實資產處置之程序
C
該組織可能未落實實體及環境安全之程序
D
該組織可能已落實存取控制政策
答案解析
問題描述的核心是離職員工帳號未被及時停用，並發生了未授權的存取行為。
(A) 使用者存取管理程序應包含使用者到職、異動、離職等整個生命週期的帳號與權限管理。離職員工帳號未停用，直接反映了離職相關的存取管理程序未被落實或存在缺陷。這是最直接相關的問題。
(B) 資產處置程序通常指對硬體或儲存媒體報廢、汰換時的資料銷毀或設備處理，與使用者帳號管理關係較小。
(C) 實體及環境安全主要關注物理環境的保護（如門禁、監控），與帳號管理無直接關係。
(D) 如果存取控制政策已落實，就不應發生離職員工仍能登入存取的情況。顯然政策或其執行出了問題。
因此，最合適的敘述是 (A)。

1.2 資安管理實務/架構規劃
在存取控制上, 零信任 (Zero Trust) 是一個重要課題。關於零信任的敘述, 下列何者較「不」適當?
A
零信任依循「永不信任, 一律驗證」的原則
B
推動零信任, 企業可能需要重新評估每項資產的保護方式
C
零信任倚重於最大特權原則等治理政策
D
是 Forrester 的 John Kindervag 首次創造的一個名詞
答案解析
關於零信任 (Zero Trust) 的核心概念：
(A) 「永不信任，一律驗證」 (Never Trust, Always Verify) 正是零信任的核心指導原則，不基於來源位置或網路區域提供隱式信任。
(B) 實施零信任需要從根本上改變過去基於邊界的防護思路，對所有資源（資料、應用、服務、設備）的存取進行細粒度控制，因此需要重新評估保護策略。
(C) 零信任強調的是「最小權限原則」 (Principle of Least Privilege)，即只授予完成任務所必需的最低權限，而非「最大特權原則」。最大特權是零信任要避免的情況。
(D) 零信任這個概念確實是由時任 Forrester Research 分析師的 John Kindervag 在 2010 年左右首次提出並推廣。
因此，較不適當的敘述是 (C)。

1.1 ISMS建置實務與法規遵循
從 ISO 27001:2022 附錄A「參考控制目標及控制措施」中, 下列哪些是「實體控制措施」相關的規範或控制措施?
A
實體進入控制措施
B
遠端工作應提出申請
C
維護設備, 以確保其持續之可用性及完整性
D
未經事前授權, 不得將設備、資訊帶出場域外
答案解析
ISO 27001:2022 附錄A 將控制措施分為四個主題：組織 (Organizational)、人員 (People)、實體 (Physical)、技術 (Technological)。
「實體控制措施」 (A.7) 關注的是對物理環境、設備和資產的保護。
(A) 實體進入控制 (A.7.1, A.7.2)：管理對辦公室、機房等實體區域的進入權限，屬於實體控制。
(B) 遠端工作 (A.6.7)：規範遠端工作的安全要求，屬於人員控制 (People controls) 或組織控制 (Organizational controls) 的範疇。

B
須觀察與量測所擁有資產與相關資產, 其完整性與安全態勢
C
運算服務 (Computing Service) 和資料來源 (Data Sources) 皆可視為資源

C

  • **預防性 (Preventive):** 旨在防止資安事件發生。
  • **偵測性 (Detective):** 旨在發現正在發生或已發生的資安事件。
  • **矯正性 (Corrective):** 旨在事件發生後，採取行動修正問題、減少衝擊或恢復正常狀態。
系統資料備份的主要目的，是在原始資料遺失或損毀（事件發生）之後，能夠將資料恢復回來。這個「恢復」的動作屬於事後補救的性質。因此，資料備份（及其對應的恢復程序）主要屬於矯正性控制措施。

【題組5 背景描述如前】風險處理實務中, 針對定量分析 (Quantitative), 可以計出精準的風險危害程度, 計算出可被度量的數值, 一般來說, 它是金錢的單位, 要計算出一年內單一風險因子對於資訊資產產生單一危害。經過評估, 本項網站弱點資產價值為 120 萬元, 已識別出有 3 個可利用的弱點, 可取得網站上所有員工的個人資料, 無論其弱點的多寡, 其危害網站 40% 的價值, 該 EIP 網站並未被公開於網路上, 但在過去此類內部網站弱點被利用一年內約有 12% 的弱點被利用, 請問其年損失期望計算下列何者正確?
A
120 萬 * 3 * 40% * 12%
B
(120 萬 * 3 * 40%) - (120 萬 * 12%)
C
(120 萬 * 40%) * 12%
D
(120 萬 * (40%/3)) * 12
答案解析
年損失期望值 (Annualized Loss Expectancy, ALE) 的計算公式為：
ALE = 單次損失期望值 (Single Loss Expectancy, SLE) * 年發生率 (Annualized Rate of Occurrence, ARO)
其中，SLE = 資產價值 (Asset Value, AV) * 暴露因子 (Exposure Factor, EF)
EF 指的是單次風險事件發生時，資產價值損失的百分比。
ARO 指的是風險事件在一年內發生的頻率或機率。
根據題目資訊：
  • 資產價值 (AV) = 120 萬元
  • 弱點數量 = 3 個 (這個資訊在 ALE 計算中通常不直接使用，ARO 關注的是事件發生的頻率，EF 關注的是單次事件的損失比例)
  • 單次事件的危害價值（損失比例）(EF) = 40% (題目說「無論其弱點的多寡, 其危害網站 40% 的價值」)
  • 年發生率 (ARO) = 12% (題目說「一年內約有 12% 的弱點被利用」，這裡假設這代表該類風險事件發生的年機率)
計算 SLE:
SLE = AV * EF = 120 萬 * 40%
計算 ALE:
ALE = SLE * ARO = (120 萬 * 40%) * 12%
對應選項 (C)。
